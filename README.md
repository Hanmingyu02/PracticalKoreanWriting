# 바른 — 실용글쓰기 연습장

한국실용글쓰기 공부를 위한 정적 웹 앱입니다. 별도 서버, API 키, 빌드나 패키지 설치 없이 동작합니다.

## 기능

- 제공받은 770개 항목을 직접 입력 퀴즈로 제공: 일본어 투 용어 51개, 개선 대상 한자어 56개, 개선 대상 외래어·외국어 51개, 맞춤법 19개, 띄어쓰기 135개, 낱말(표기 포함) 166개, 어법·어문 규범 113개, 표현 수정 179개
- 한 순환 안에서 중복되지 않는 무작위 출제 및 복수 영역 선택 (영역 버튼을 누르고 문제 시작 버튼으로 새 회차 시작)
- 영역별 용어·다듬은 말 학습노트 및 검색 (확인 대기·참고 자료 2개는 학습노트에만 표시)
- 단권화 노트: 사용자가 제공한 객관식 개념 정리를 `concepts.js`에 저장하고 읽기 전용으로 표시 (문제·학습 기록과 별도 관리)
- 오답 노트, 정답률, 연속 정답, 브라우저 학습 기록 저장
- 모의고사 탭: 제공받은 2025 시험지 예시 1·2 및 정답 PDF 열기·다운로드
- 아이폰·아이패드 11인치·PC 반응형 화면 및 키보드 조작 지원 (태블릿 세로: 위아래 배치, 가로: 사이드 메뉴)

직접 만든 예제 문제는 모두 삭제했습니다. `questions.js`에 사용자가 제공한 용어와 다듬은 말을 저장합니다. 정답은 제공 자료를 따릅니다. 맞춤법·띄어쓰기·낱말(표기 포함) 문제는 공백과 문장부호까지 비교하며, 괄호 안의 실제 문장도 보존합니다. 아래의 공백 무시 규칙은 용어 풀이에만 적용합니다. 다듬은 말이 여러 개면 하나만 입력해도 정답이며, 띄어쓰기 차이와 괄호 안의 맥락 설명은 채점에서 제외합니다. 쉼표나 빗금으로 여러 답을 입력하면 모두 정답 목록에 있어야 합니다. 기록에 사용하는 기존 문제 ID는 유지하세요. 다듬은 말은 문맥에 따라 선택해야 하며 모든 외래어나 한자어가 잘못된 표현이라는 뜻은 아닙니다.

## 로컬 실행


```sh
cd /workspace/PracticalKoreanWriting
python3 -m http.server 8000 --bind 0.0.0.0
```

일반 개발 환경에서는 브라우저로 서버에 접속합니다. 앱 자체는 `index.html`을 직접 열어도 실행할 수 있지만 기록 저장 동작은 브라우저 정책에 따라 달라질 수 있습니다. Google Fonts에 접근할 수 없어도 시스템 글꼴로 동작합니다.

## GitHub Pages 무료 배포

공개 저장소는 GitHub Free의 Pages를 사용할 수 있습니다. 비공개 저장소의 Pages 사용 가능 여부는 GitHub 요금제를 확인하세요.

1. 파일을 GitHub의 `main` 브랜치로 푸시합니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
3. **Actions → Deploy to GitHub Pages → Run workflow**를 실행합니다. 이후 `main`에 푸시할 때마다 자동 배포됩니다.
4. 성공한 배포의 주소는 `https://hanmingyu02.github.io/PracticalKoreanWriting/`입니다.

배포 워크플로는 웹 앱 파일 다섯 개와 `assets/`의 PDF 자료를 업로드합니다. 로컬 학습 기록은 브라우저별로 관리되며 계정 간 동기화되지 않습니다.
